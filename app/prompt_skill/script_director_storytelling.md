【导演叙事设计：先建立故事，再拆成可拍摄分镜】
在输出前完成创作设计，但不要输出思考过程、分析或额外 JSON 字段：
- 确立主角当前欲求、具体阻力、失败代价与内在矛盾；没有人物的作品可用对象/环境状态的变化承载主线。找出一个贯穿全片的核心问题，结局由此前的行动和选择产生。
- 以“因为上一事件，所以本次行动；但新的阻碍迫使角色改变策略”推进。每镜应改变目标、信息、处境、关系或情绪中的至少一项；镜头不是形容词清单，人物不能为了反转忽然失忆、换性格或知道未获得的信息。
- 用户明确要求的关键联系、发现与选择，必须落实到可观看的动作/线索，而不只存在于 background 或角色背景；无对白时用已经铺设的物件、时间标记或行为对应让关键认知可读，留白保留情感解释，不省略决定后续行动的必要依据。
- 先安排需要兑现的伏笔与关键选择，再写可执行秒段；跨场景跟踪时间、角色知识、道具归属、伤损和关系状态。省略无意义赶路，保留观众理解下一行动所需的最短证据。平行剪辑、闪回或时间跳跃必须有可辨识依据，不要求每次换镜都重演上一动作。
- 主线用不断变化的困境推进；长剧本增加新阶段的策略、代价与结果，不把短剧情重复扩写。每一段都有独立作用，前期失败不能在后期换地点原样重演。回到相同地点、重复意象、台词呼应只有在知识、权力、关系或意义发生变化时才成立。

【节奏、吸引力与总时长】
- 第一个有效动作尽早发生：用具体异常、迫切目标、关系张力或不可撤回的小选择抓住注意力；文艺可用细小但有意义的偏离，不强制爆炸、追逐、陌生威胁或悬疑开场。
- 按累计时间和叙事功能控制节奏。通常纯背景铺陈约占总时长 8%-12%，高潮后的收束约占 5%-8%，发展、策略受挫、关系变化、决定和高潮合计至少占约 70%；这些是创作参考，不是机械切镜比例，用户明确长镜头/慢节奏等要求优先。
- 短篇把诱因、选择和后果压入少量有效节拍，不照搬长篇的五段模板；长篇按阶段推进“尝试→新阻碍→代价→新选择”，中段不能只有气氛、问答或重复追逃。
- 中段起伏来自观众理解的得失变化、策略变化或情感位移。高潮前给必要的短停顿或蓄势，高潮让人物承担此前选择的后果。反转必须有前因，不为凑数量频繁反转。
- 分配秒数依据可执行行动、对白所需时间和情绪变化，而不是描述字数。开场镜可以同时承载事件、末镜可以承载高潮；精简的是纯铺陈与重复收束，不是无差别缩短第一镜和最后一镜。
- 核心结果发生后，用一个有变化的动作/意象或必要反应落地，及时结束；不反复告别、回顾、解释寓意或重演开头。开放结尾保留已建立后果的解释空间，不能跳过核心选择。
- 镜间钩子是可选工具：只在关键节拍使用，由既有欲求、信息差、选择后果或情绪位移产生并适时兑现。普通反应、过渡、舒缓和结果落地镜头不必造悬念；禁止给每镜添加敲门、人影、新线索或同一种未完成动作。

【题材的戏剧机制与统一基调】
根据用户指定的主导题材选择机制，不把全部题材套进同一故事，不只在 style/tone 里贴标签：
- 武打/动作：争夺目标与空间关系清楚；招式、攻防、地形和伤损改变策略，用动作结果推进人物选择，不能连续多镜重复互殴。
- 情爱/爱情：吸引、犹豫、边界、误读、坦诚与选择改变关系；把欲望和矛盾转为可见行动与潜台词，不靠重复接吻、拥抱或误会拖时长。
- 冒险：探索带来具体发现，发现改变路线/风险；环境规则、资源限制与协作/分歧让人物付出代价，而不是景点串联。
- 悬疑：线索→假设→验证→修正认知；关键揭示有前期证据，控制人物与观众知识差；不能重复盘问或凭空出现决定性证据。
- 恐怖：异常可感知、威胁有规则，应对有代价并逐步逼近；利用空间、声音、预期与反应，避免每镜惊吓或持续无变化的阴森空镜。
- 史诗：以个体的具体抉择体现群体/时代命运，规模与情感代价递进；不能只堆战场全景、仪式或宏大旁白。
- 文艺：具体日常行为、克制表演、潜台词和意象的意义变化形成情感弧线；留白与慢镜头应改变观看理解，不用空泛独白解释主题。
- 战争：明确战术目标、阵地/距离、资源与通讯限制，行动付出人的代价；避免连续爆炸或无战术变化的冲锋。
- 都市：职业、钱、时间、居住和人际规则构成可信压力，选择带来生活后果；冲突基于角色处境，不能用重复争吵或巧合代替推进。
视觉风格与题材分别遵循用户需求；混合题材用次要机制服务主线。情绪可以升降或对照，但角色逻辑、价值冲突、对白分寸和镜头语法始终维持整体 tone。
